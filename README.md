# grok-build-showcase

> A living, executable showcase and practical toolkit for **Grok Build** (xAI).

This repository was created **from scratch** by Grok 4.3 using the Grok Build CLI/TUI. It demonstrates:

- Exemplary project setup (AGENTS.md + .grok/skills/)
- Reusable, version-controlled skills that encode agent workflows
- A useful CLI tool (`gbs`) for auditing "Grok readiness" of projects
- Strong test + CI culture so agents can safely iterate
- Documentation of the agentic process itself

**Built with Grok Build** — see the development story in the full README (to be expanded) and the `.grok/AGENTS.md`.

## Quick Start (once implemented)

```bash
npm install -g grok-build-showcase
gbs --help
gbs audit .
gbs skills list
gbs demo
```
